# 成熟人物基础：同一样本的 Rust A/B

日期：2026-10-16。入口：[研究建议](../../docs/research/character-foundation/README.md)；[共同执行合同](CONTRACT.md)；[实测结论与下一道门](RESULTS.md)。本轮只在隔离实验中验证成熟人物数据，不替换主线角色或选择生产依赖。

## 当前进展

本机 Blender 已按人的授权通过 Homebrew 从 **3.3.1 升级到 5.2.2 LTS**，保留新版。版本、安装包 SHA256、后台启动及实际 MPFB 运行已验证。[升级收据](delivery/blender-homebrew-upgrade.json)记录准确目标。原计划的独立 Blender 4.2.23 DMG 已取消，没有下载。

其余已批准输入共 **327,316,919 字节**，已下载/复用并完成来源、归档与许可证审计。MPFB 2.0.18 的发布包只有入口文件的三个构建标记与固定源码 tag 不同；图形数据逐文件一致。原始[下载请求](downloads/DOWNLOAD-REQUEST.md)和[manifest](downloads/manifest.json)保持不变；实际结果见[交付报告](delivery/README.md)。没有下载未知传递依赖，也没有运行新模型或使用额外机器/付费资源。

实际 Blender/MPFB 参考现已完成：同一个 raw hm08 身体、53 根 GameEngine 骨骼、一件 `female_sportsuit01`，以及躯干和下巴各一对真实 target。八组参数均实际求值，包含 **19,158 个身体顶点和 1,797 个衣物顶点**。原始身体包含骨骼 helper，不能把它的顶点数直接当成最终渲染身体规模。精确坐标、捕获规则、来源和复现命令见[参考说明](reference/README.md)。

两条 Rust 路径必须使用同一个冻结 manifest：`2e8566a4f12de710ead88f6aa2d71fc44e0680761a4f2fdc48a844b6f3534ab7`。容差在全样本比较前固定为每个参考米制坐标分量 `1e-5`；这只衡量数值一致性。

| 路径 | 实际结果 | 未验证范围 |
|---|---|---|
| [A：离线编译人物包](../54-compiled-character-package/REPORT.md) | 实际 Rust 求值与 MPFB 八组样本对照，身体、骨骼端点和衣物均在预定数值容差内。最大分量误差分别约 `3.81e-7`、`2.54e-7`、`3.02e-7` 米。完整结果、拒绝控制与局限以该路径报告为准。 | 骨骼 roll/rest/逆绑定、姿态蒙皮、桌面/Web 图形、作品交换和视觉质量。 |
| [B：Humentity 源数据运行时](../55-source-character-runtime/REPORT.md) | B0 实际运行八组，因小形变过滤产生约 0.9 mm 身体误差而失败。只修改这一行阈值的隔离 B1 实际重跑八组，身体、衣物与骨骼头部位置通过同容差。原始失败与输出保留。 | 尾端点未公开；完整 rest/逆绑定坐标系、姿态蒙皮、桌面/Web、正式 CLI 与作品交换未验收。 |

A 由同一批源文件编译 sparse target、helper 骨骼规则和衣物绑定；B 调用真实已有 Rust 库，经明确记录的格式/单位适配取得同样本。参考输出只用于比较，不能作为两条路径的生成输入。完整数组、下载文件和构建缓存保留在忽略的 `.work/` 中，仓库只存代码、摘要与来源哈希。

## 准入边界与下一步

本轮数值结果不能直接推出人物系统已采用。下一道门是骨骼 rest/逆绑定与抬臂、屈肘、屈膝的真实蒙皮，再分别验证 CLI、桌面、Web、整份作品保存交换和有界资源开销。完整皮肤、眼睛、头发、动漫审美与旧 MakeHuman GLSL 材质外观仍未验证。
