## Check a new capture

```sh
PYTHONDONTWRITEBYTECODE=1 python3 /path/to/verification/check_capture.py \
  --repo /path/to/nvwa \
  --capture /path/to/actual-capture-envelope.json \
  --command /path/to/independently-recorded-sent-command.json \
  --receipt /path/to/separately-read-current-compact-report.json \
  --output /path/to/NEW-result.json
```

The output file must not exist. `--capture` is exactly `{request,report,frame}`. `--command` must be the saved sender command, not copied from the tested capture to manufacture an expected value. `--receipt` must be a separately read captured compact report. Native collection may assemble this envelope from separately recorded actual frame/report and command files while preserving those originals. No offline arrays may replace missing actual arrays.

The bundled source-freeze-r5.json pins the13 original experiment files. All current repository bytes must match. The checker also authenticates all12 prepared source payloads and original stable53 weights, plus the included source_reference.py hash. Adding this verification directory does not change the13-file map. A changed original file, missing input, stale/mismatching receipt or missing actual field fails. This deliberately pins the r4 compiled renderer schema with the r5 Python capture sink: another source version needs an explicit reviewed version/identity update.

The reference keeps signed normalized helper coefficients, ordered signed axis scales,0.1 conversion of offsets/reference lengths, all positive FINAL joint aggregates with no top4 pruning, normalized full influences, actual skin matrices and one display placement. The inherited1e−5m arithmetic guard,1e−6 UV guard and exact positive-joint sets are unchanged. Actual render positions/normals/UV/indices are read from the input export; original source/UV-index pairs and ordered fan/winding are checked exactly. Current bound material/image CPU observations and model/stage bounds are checked. Every frozen full/compact accessory and nested material observation field is required; truncated records cannot remove their own comparisons. Upload hashes require64lowercase hexadecimal characters and exact full/compact equality; the checker does not recompute Rust JSON digests. Missing tangents remain explicitly NOT-EXPORTED; finite/unit normals do not prove smoothing parity.

These checks produce source-grounded arithmetic evidence. Command/report/frame are same-producer protocol binding, and53 BoneFrame comparisons are internal consistency. They are NOT an independent current-world freshness oracle, MPFB/Blender reference, GPU readback, eye/eyelid/hairline visual assessment, gaze, collision or hair physics. A wholly consistent stale bundle can pass; tests demonstrate this limit. Collector time/order/platform/source/binary provenance must be recorded outside the producer's self-report. Geometry/upload SHA fields are checked for producer consistency; Python re-serialization is not claimed to reproduce Rust JSON byte hashes.
