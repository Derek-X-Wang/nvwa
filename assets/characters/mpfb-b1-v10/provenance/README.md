# Static chest placement source extension (v10)

Four CC0 MPFB 2.0.18 targets are fixed by compressed SHA256 in `scripts/build-chest-placement-v10.py`. `chest-placement-target-source.json` records the source URL and hashes. Each shipped target is the exact gzip expansion; the runtime scales MPFB coordinates by 0.1 once.

The two signed controls are unitless authored target weights. For vertical position, negative selects `down` and positive selects `up`; no centimetre or physical measurement is implied. All 55 predecessor runtime payloads are byte-identical. Static rendering does not establish garment fit, full animation quality, or safety of extreme parameter combinations.
