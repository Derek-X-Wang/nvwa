# Upper-arm muscle target extension (v14)

This profile extends merged v13 and preserves all 63 earlier runtime payloads byte for byte. The separate v10 chest-placement experiment remains on visual hold and is not inherited.

`upper-arm-muscle-target-source.json` pins four CC0 MPFB source targets at one commit. Each shipped bilateral target concatenates the left and right expanded source rows sorted by vertex ID; the two ID sets are disjoint and no displacement is edited. The runtime applies its usual single 0.1 displacement scale. The signed weight is relative, not a measurement of anatomical upper-arm girth or measured muscle mass.

Body-only static views and saved poses can check shape and continuity. Elbow transition, clothing fit, continuous animation and artistic quality require separate acceptance.
