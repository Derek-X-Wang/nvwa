# Bilateral leg target source extension (v6)

`leg-target-source.json` records eight newly admitted targets from the pinned MPFB 2.0.18 source. Each runtime `.target` is the exact gzip expansion of its archived source file under `source/data/targets/legs/`; no amplitudes, IDs, signs or zeros were edited. Only CC0 target data was imported, not addon program code. The existing runtime loader converts source coordinates by 0.1 once.

The four controls select the original increase or decrease endpoint with a nonnegative magnitude, as earlier B1 parameters do. These are unitless, relative shape weights, not centimetres, measured anatomical segment lengths or equal perceptual steps. The length targets include helper/joint-cube vertices; fitted skeleton, clothing, posed legs and feet need actual runtime examination.

`legacy-v5-manifest.json` and `legacy-v5-runtime-payloads.json` preserve the immediate predecessor. All 31 v5 runtime payloads are byte-identical in v6. `runtime-payloads.json` and `../manifest.json` enumerate the current 39-file runtime set. The older provenance files remain historical evidence for the prior cheek, chin and waist extensions; their counts and hashes do not describe the v6 set.

All prior quality HOLDs remain. A static silhouette or successful asset check alone does not approve garment quality, animation or character art.
