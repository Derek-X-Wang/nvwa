Source commit: d0a32e57a7f915cb2f2b95410e2117648c7bbb7e.

`lower_face_squareness` is an Nvwa one-sided contour control in [0,1], default0.
Only the exact authored chin-bones-incr displacement (E) can receive positive
weight. The original chin-bones-decr data (A) is retained, authenticated and loaded
only because the existing fixed target binding uses a pair. Negative public values
reject. Retention of A is not adoption; A's usefulness/transition HOLD remains.
No endpoint was inverted, cropped, repaired, scaled or synthesized. gzip expansion
preserves every original text byte and zero row. The existing loader converts units.

The result is lower-face contour squaring, not literal jaw width or anatomical
isolation. Adjacent height/depth and jaw-to-neck transitions can change. Source
reference signal does not establish product, attachment, motion or all-shape quality.
