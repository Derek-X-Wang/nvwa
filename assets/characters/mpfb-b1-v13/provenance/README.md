# Forearm-fat target extension (v13)

This profile extends merged v12 and preserves all 61 earlier runtime payloads byte for byte. The separate v10 chest-placement experiment remains on visual hold and is not inherited.

`forearm-form-target-source.json` pins four CC0 MPFB source targets at one commit. Each shipped bilateral target concatenates the left and right expanded source rows sorted by vertex ID; the two ID sets are disjoint and no displacement is edited. The runtime applies its usual single 0.1 displacement scale. The signed weight is relative, not a measurement of anatomical forearm circumference or muscle mass.

Body-only static views and saved poses can check shape and continuity. Grip, clothing fit, continuous animation and artistic quality require separate acceptance.
