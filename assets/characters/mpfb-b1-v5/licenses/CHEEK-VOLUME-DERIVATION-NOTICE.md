# Bilateral cheek volume data

These two CC0-1.0 graphical target files derive from MakeHuman MPFB 2.0.18,
commit d0a32e57a7f915cb2f2b95410e2117648c7bbb7e. The four original compressed
CC0 graphical source files are retained under provenance/source/data/targets/cheek/.
See provenance/cheek-volume-derivation.json for exact public source URLs,
compressed and expanded identities, counts, deterministic recipe, and outputs.

For each sign the stored left and right vertex ID sets are disjoint. The output
is their sorted full union with original numeric tokens and zero rows retained.
There is no arithmetic, mirroring, averaging, rescaling, or source-unit conversion.
The existing runtime loader owns its single conversion. No upstream plugin or
configuration code was copied. Existing source notices and license texts remain
unchanged; they describe their original payloads, not a new quality acceptance.
