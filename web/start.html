  1. 调整角色进入 Studio 后选中角色，拖动 Shape 滑块。Undo / Redo 可撤销或重做修改。
  2. 保存到本机点击工具栏 Save，浏览器会下载 JSON 作品文件。请保留下载的文件。
  3. 重新打开再次进入 Studio，点击 Open，选择之前下载的 JSON 文件，即可继续编辑。
Studio 需要支持 WebGPU 的桌面浏览器。体型编辑与文件保存已提供；人物外观和衣物效果仍在完善中。
