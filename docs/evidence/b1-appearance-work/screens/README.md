The acceptance panel visible in some Web images identifies instrumented66.
It uses the production Studio and rendering path. These exchange images must
not be relabeled as uninstrumented product screenshots. Initial product Studio
and Player images above are separate ordinary entrypoint observations.

`inventory.json` records each public relative filename, original local basename,
SHA256, byte count, dimensions and actual media type. The original files used
`.png` names but contain JPEG/JFIF bytes. Public extensions are corrected to
`.jpg`; bytes are unchanged, with no re-encoding, cropping or image synthesis.
Every selected image was visually inspected for private paths and unrelated
desktop content. Private path-bearing Save-toast images were excluded.

These images belong to the r4 GUI source cohort. Later CLI-only help changes
have their own source/binary receipt. Image dimensions and file sizes are
inventory data, not performance measurements. The images do not admit full
hairline, eye, clothing, M2 motion or overall visual quality.
